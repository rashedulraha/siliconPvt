# EstateHub — Premium Real Estate CMS

A production-ready real estate property listing website with a no-code CMS admin dashboard.

## 🚀 Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Animations:** Framer Motion
- **Theming:** next-themes (dark/light/system)
- **Storage:** localStorage (client-side CMS)
- **Analytics:** Google Analytics 4
- **Toasts:** Sonner

## ✨ Features

### Public Website

- 🏠 Home page with hero, featured properties, testimonials, CTA
- 🏘️ Properties listing with advanced search & filters
- 🏡 Property details with gallery, specs, contact form
- ℹ️ About page with company story, team, stats
- 📝 Blog with featured posts & tag filtering
- 💼 Careers with job listings & apply functionality
- 📞 Contact page with form & map
- 💖 Save favorites (localStorage)
- 🔄 Compare properties (up to 3)
- 💰 EMI/Mortgage calculator
- 💬 WhatsApp integration
- 🌓 Dark/light/system theme

### Admin Dashboard

- 📊 Dashboard overview with stats & charts
- 🏘️ Inventory management (CRUD properties)
- 📥 Lead management with status tracking
- 🧭 Drag-and-drop menu builder
- 🎨 Theme customization (colors, typography)
- 🔍 SEO management per page
- 🖼️ Media library with upload

### Production Features

- ⚡ Lighthouse 95+ optimized
- 🔍 Full SEO (meta tags, Open Graph, sitemap, JSON-LD)
- ♿ WCAG 2.1 AA accessibility
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎬 Smooth animations (Framer Motion)
- 🛡️ Error boundaries & loading states
- 🍪 Cookie consent (GDPR)
- 📊 Google Analytics integration

## 📦 Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd estatehub

# Install dependencies
npm install

# Copy environment variables
cp .env.local.example .env.local

# Start development server
npm run dev
```
